# 在线设备页操作引导设计

## 背景

在线设备页顶部现在有“加载全部”“刷新”和“接口配置”三个操作按钮。新用户可能不清楚分页加载和刷新行为，因此需要在页面进入时用一次 Overlay 同时说明三个按钮的作用。

## 范围与交互

- 将顶部按钮顺序固定为：左侧“加载全部”、中间“刷新”、右侧“接口配置”。
- Overlay 一次同时展示三个说明卡片，卡片从左到右分别对应这三个按钮。
- 每张卡片使用标题、说明文字和箭头指向对应的顶部按钮。
- 说明内容为：
  - 加载全部：自动加载所有分页，不用再上拉加载更多。
  - 刷新：清空当前列表，重新加载第一页。
  - 接口配置：切换在线设备接口配置。
- Overlay 提供“知道了”按钮关闭引导，并阻止用户在引导期间误触页面操作。
- 前 3 次进入在线设备页时显示完整引导，第 4 次及以后不再显示。
- 只读在线设备页没有接口配置按钮，不显示该三按钮引导。

## 实现方案

`OnlinePage` 使用 `SharedPreferences` 保存已展示次数，并在首次列表加载完成后的下一帧检查是否需要显示引导。三个顶部按钮使用 `GlobalKey` 获取全局位置，页面级 `OverlayEntry` 通过这些位置绘制箭头；按钮顺序调整为加载全部、刷新、接口配置。

引导组件和箭头绘制逻辑放在 `online_page.dart` 内，避免为一次性页面引导新增第三方依赖。页面级 Overlay 容器托管底层页面和引导 entry，引导 entry 使用不可关闭的 `ModalBarrier` 实现半透明遮罩和模态交互。

## 错误处理与生命周期

- 偏好设置读取失败时不显示引导，不影响在线设备列表。
- 页面销毁后不显示 Overlay 或更新状态。
- 展示次数在显示前写入，避免页面重建造成重复计数。
- 关闭引导不会触发刷新、加载全部或配置操作。

## 验证

- Widget 测试确认三张说明卡片和箭头引导入口出现。
- Widget 测试确认前三次进入显示，第 4 次进入不显示。
- Widget 测试确认关闭按钮可以移除 Overlay。
- 运行在线页相关测试、完整 `flutter test` 和 `flutter analyze`。

## 非目标

- 不引入第三方引导库。
- 不改变三个按钮的业务逻辑和接口协议。
- 不为只读页增加接口配置按钮。
