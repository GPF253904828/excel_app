# 首页大厅与本地配置页设计

## 目标

移动端首页改为“大厅”，只提供“在线”和“本地”两个入口。点击“在线”进入现有在线设备管理页，点击“本地”进入独立的本地文件配置页。

## 范围

- `HomePage` 和 `HomePageView` 只负责大厅展示与导航。
- 新增 `LocalPage`，承接现有首页中的局域网文件传输和本地文件管理能力。
- 复用 `HomePageController`，保持 IP、端口、服务启停、文件接收、表格编辑、导出和删除行为不变。
- 文件服务在进入 `LocalPage` 后初始化，在离开页面时释放。
- 现有 `OnlinePage` 不改变，桌面端 `PCHomePage` 不纳入本次修改。

## 页面与数据流

`HomePage` 通过 `Navigator.push` 分别打开 `OnlinePage` 或 `LocalPage`。`LocalPage` 持有一个 `HomePageController`，监听控制器状态并将原有回调连接到本地配置视图。打开接收文件、编辑表格和导出二维码的流程继续使用现有服务和页面组件。

## 错误处理

- 本地服务初始化失败时沿用控制器的失败状态并展示。
- Excel 读取失败时沿用现有 Toast 提示。
- 删除文件继续使用二次确认。
- 本地页销毁时释放控制器，避免文件服务和监听器泄漏。

## 测试

- 首页视图测试验证只展示在线、本地入口，并验证两个回调。
- 本地页测试验证能渲染现有 IP/服务状态入口，并验证点击本地入口后进入本地页。
- 运行本次涉及文件的 Flutter 测试、定向静态分析和 `git diff --check`。
