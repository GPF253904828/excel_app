# 在线列表与导出服务设计

## 目标

保持首页“在线”入口文字不变。进入在线页后立即读取 AirScript 的 `list`
接口，使用现有表格页面的视觉样式展示全部设备。所有新增、修改和删除均
直接调用线上接口；操作成功后重新拉取列表，保证页面与在线表格一致。

首页不提供导出入口。用户在二维码页生成图片后进入二级导出页；该页面显示
服务控制、局域网地址、运行状态和待导出的二维码文件，并供电脑下载。

## 架构

- `DeviceApi` 增加 `listDevices`，发送 `{type: 'list'}`，并将脚本返回的
  `rows` 解析为类型化列表结果。
- `OnlinePage` 在初始化后加载列表。它以 `SpreadsheetPage` 的表格视图作为
  主内容，始终优先按既定的 15 个设备字段排序；接口返回的额外字段追加到末尾。
- `SpreadsheetPage` 增加可选的行级远程保存与删除回调。提供回调时，新增、
  修改和删除成功后替换为在线页重新拉取的完整表格，避免保留陈旧本地行。
  本地 XLS 流程继续使用现有的“列表页保存后导出”行为。
- `HomePage` 持有唯一的 `HomePageController`，将它传给本地页、在线页和导出页。
  因此导出页启动的服务也能被在线二维码页复用。
- `ExportPage` 仅由二维码生成页打开。它复用 `LocalPageView` 的视觉语言与服务
  状态，展示待导出的二维码 ZIP，并在用户确认后将该 ZIP 发送给电脑。
- `OnlineConfigStore` 存储配置列表和当前选中项。应用内置一组 URL/Token 作为
  默认配置，内置项不可修改或删除；旧版单条配置迁移为自定义项。
- `OnlineConfigPage` 改为配置列表页。它展示每项 URL、Token 和内置标识，并在
  页内弹窗中新增或编辑自定义项。选择配置后，用户点击“确认使用”才持久化选中项
  并返回在线页；新增入口放在应用栏，避免与底部确认按钮重叠。

## 数据流

1. 用户点击“在线”，页面读取已保存的接口配置并调用 `list`。
2. 远端 `rows` 转为表头顺序一致的二维行数据并显示。
3. 新增、编辑或删除调用对应接口；成功后再次调用 `list` 刷新。
4. 用户在表格中生成二维码，二维码图片暂存于应用文档目录的 `二维码合计`。
5. 二维码页生成 `二维码合计.zip` 并将其带入二级导出页。
6. 用户点击在线页的接口配置图标，进入配置列表；选中配置并确认后返回在线页，
   在线页用新配置重新调用 `list`。
7. 用户在二维码页生成图片后点击“导出”，进入二级导出页；该页启动服务、展示
   局域网地址和状态，用户点击“导出二维码”后才将 `二维码合计.zip` 排队下载。

## 错误处理

- 未配置接口时显示现有配置提示，不展示陈旧数据。
- 列表请求或行操作失败时保留当前列表，并显示可读错误消息。
- 二级导出页点击导出时服务未运行，会先启动服务；启动失败时保留 ZIP 并展示错误。
- 表格缺少二维码所需字段时，沿用现有提示，不生成空文件。
- 自定义配置的 URL 或 Token 为空、URL 无协议时，阻止保存并在编辑弹窗中提示。
- 删除当前选中的自定义配置时，自动回退为内置配置，避免在线页持有无效选项。

## 验证

- 网络层测试验证 `list` 请求体、Token 和 `rows` 解析。
- 在线页测试验证进入即加载列表，及增改删后重新加载。
- 二维码页测试验证默认目录和 ZIP 文件名使用 `二维码合计`。
- 导出页测试验证服务状态、局域网地址与待导出文件状态。
- 配置页测试验证内置项只读、自定义项可增删改、确认选择后更新活动配置并触发
  在线列表刷新。
